# Mongolian writing

- Default: natural, human, clear Mongolian. Short sentences. Avoid bureaucratic chains ("…-тай холбогдуулан …-ын талаар …").
- Formal register only for: албан бичиг, tender documents, academic lectures.
- Institution: **МГТИС** (Монгол-Германы Хамтарсан Ашигт Малтмал, Технологийн Их Сургууль) — never МГТИ.
- Faculty: "Эрдэс баялаг, хүрээлэн буй орчны инженерчлэлийн факультет".
- Албан бичиг: use Ochir's own existing letter files as template + his signature and stamp images; never design a new letterhead.
- Technical terms: give the English term in brackets the first time, e.g. флотаци (flotation), баяжмал (concentrate), хаягдал (tailings).
- Read the text once more for spelling of ө/ү, and vowel harmony in suffixes before delivering.
