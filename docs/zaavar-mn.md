# GitHub ба AI баг — энгийн заавар

*— Esther (CEO), Очирт зориулав*

## 1. GitHub гэж юу вэ?

GitHub бол таны бүх ажлын **ухаалаг архив** юм. Файл бүрийн өөрчлөлтийг хэн, хэзээ, юуг өөрчилснөөр нь хадгална. Алдаа гарвал өмнөх хувилбар руу нэг товчоор буцна.

Гэхдээ хамгийн чухал нь: GitHub дээр **робот** ажиллуулж болно. Та файл оруулах бүрт робот автоматаар шалгаж, туршиж, вэб дээр байршуулна.

## 3. Хавтас бүр юу хийдэг вэ?

| Хавтас / файл | Энгийнээр |
|---|---|
| `CLAUDE.md` | Claude-ийн **ажлын дүрэм**. Claude энэ репод орох бүртээ эхлээд үүнийг уншина. |
| `.claude/skills/` | **Ур чадвар** — "симулятор яаж хийх", "монголоор яаж бичих", "гаргахаас өмнө юу шалгах". |
| `.claude/agents/` | **Багийн гишүүд** — Esther, Nora, Leo, Jacob … тус бүрийн үүрэг. |
| `.claude/settings.json` | **Зөвшөөрөл** — Claude юу хийж болох, юу хийж болохгүй (нууц файл унших, хүчээр устгахыг хориглосон). |
| `simulators/` | **Симуляторууд** — эхнийх нь зэсийн флотацийн үйлдвэр. |
| `tests/` | **Шалгалтууд** — тооцоо зөв үү, хуудас нээгдэж байна уу, сайт ажиллаж байна уу. |
| `.github/workflows/` | **Роботууд** — GitHub дээр өөрөө ажилладаг. |
| `team/<нэр>/` | Бот бүрийн ажлын хавтас. |

## 4. Гурван робот

1. **CI – test everything.** Өөрчлөлт орох бүрт: тооцооны тест (масс баланс 10⁻⁹ t/h нарийвчлалтай битүүрэх ёстой) + симулятор бүрийг Chrome-оор нээж, гулсуурыг хөдөлгөж, алдаа гараагүйг шалгана. Дэлгэцийн зургийг хадгална.
2. **Deploy website.** Тест давсан бол симуляторуудыг шууд вэбд гаргана:
   https://purevochir-arch.github.io/ochir/simulators/
3. **Uptime check (интернет тест).** 6 цаг тутам monprocess.org, mongoliantour.guide болон симуляторын сайтыг шалгана. Унасан эсвэл 8 секундээс удаан бол улаан болж, GitHub танд имэйл илгээнэ.

## 5. Танд нэг удаа хийх 3 зүйл

1. **Pages асаах:** GitHub → `ochir` репо → **Settings → Pages → Source: GitHub Actions** гэж сонгоно.
2. **Имэйл мэдэгдэл:** GitHub → профайл → **Settings → Notifications → Actions** → "Only failed workflows" асаана.
3. **Профайлын нүүр хуудас (заавал биш):** `purevochir-arch` нэртэй шинэ репо үүсгэвэл түүний README таны GitHub профайлын нүүрэнд гарна. Үүсгэсний дараа надад хэлээрэй, би бөглөж өгье.

## 6. Өдөр тутам хэрэглэх

- **Шинэ ажил өгөх:** GitHub → Issues → New issue → "Ажил · Task" загвар → хэнд, юу, хэзээ гэдгийг бичнэ.
- **Ажил шалгах:** **Actions** таб → ногоон ✅ бол бүх зүйл зөв.
- **Симулятор үзэх:** дээрх линкээр орж гулсуурыг хөдөлгөөд үзнэ.
- **Claude-д хэлэх нь:** "Nora, нунтаглалтын симулятор нэм" гэхэд л хангалттай — бусдыг нь дүрэм, тест, роботууд хийнэ.

## 7. Аюулгүй байдал

- Нууц үг, API түлхүүрийг **хэзээ ч** репод хийхгүй. Хэрэгтэй бол **Settings → Secrets** дотор хадгална.
- Репо одоогоор **public** (хүн бүр харна). Хувийн материал оруулах бол тусдаа **private** репо үүсгэнэ.
